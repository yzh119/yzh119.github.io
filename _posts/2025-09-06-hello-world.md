Welcome to my minimalist blog, powered by [Jekyll](https://jekyllrb.com) and
GitHub Pages.

## Writing a new post

Create a file in `_posts/` named `YYYY-MM-DD-title.md` with front matter:

```yaml
---
layout: post
title: "My Post Title"
date: 2025-09-06 12:00:00 +0800
---
```

Then write your content in Markdown. Code blocks are highlighted:

```python
def greet(name: str) -> str:
    return f"Hello, {name}!"
```

That's it. Push to `main` and GitHub Pages builds it automatically.
