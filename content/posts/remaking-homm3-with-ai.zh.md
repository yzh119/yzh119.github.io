英雄无敌 3 是 1999 年的游戏。二十七年过去，还有人在玩，还有一群人在从头给它重写引擎。

这个系列记录一个业余项目：在 [VCMI](https://vcmi.eu) 上改美术、改战斗 AI、改玩法。
纯粹图个乐子，不商业化。

## 为什么是 VCMI

VCMI 是英雄无敌 3 的开源引擎，从头实现，兼容原版玩法和素材。它该有的扩展口都留好了：高清素材按倍率分目录、
动画用 JSON 定义、生物和技能全是数据驱动、Lua 已经接进战斗系统。

所以下面几件事可以分头做，互不影响。

## 美术

整套兵种美术换掉，走 3D 管线：概念稿 → 图生 3D → 绑骨 → 动画 → 渲染成序列帧。

这不算背叛像素风：**英雄无敌 3 的兵种本来就是 3D 预渲染的**。
骷髅的调色板有 223 种颜色，它从来不是限定调色板的像素画，是渲染结果被压到低分辨率。
走 3D 是回到原来的做法。

单个兵种 API 成本不到两块，一百五十个大约两千。花时间的是定美术方向和逐个过审。

## 更强的 AI

这条已经有人做出来了。

[smanolloff](https://github.com/smanolloff/vcmi-gym) 把 VCMI 的战斗包成了 gym 环境来训模型，
训出来的 MMAI 从 1.7.0 起就在启动器里可选，代码在主干 `AI/MMAI/`：ONNX Runtime 推理，
进攻/防守/攻城分别加载模型，带 temperature，推理失败回退传统 AI。

原版战斗 AI 是几十年前的启发式，套路固定、容易被针对。这条线接着 smanolloff 的工作做。

## 玩法机制

引擎数据驱动，改动成本比想象中低。想试地形效果、部队协同、冒险地图节奏。

还有个用法：**拿上面的 RL 环境测平衡**。改一条数值，自对弈几万局，看胜率怎么动。

## 非阻塞回合制

回合制多人最劝退的是等别人走。现有缓解是"同时回合"——没碰面各走各的，一接触退回轮流。

我想试完全异步：各走各的，不等任何人，只在真正交互时才做冲突消解。难点全在这儿——
两个玩家在各自的"当前时刻"抢同一座矿，谁先到？引入真实时间轴之后，它还算回合制吗？

这两个问题我还没想清楚。

## 关于工具和版权

coding agent 强到了一个程度，我们才敢动这个项目。代码是用 Claude Code 写的，概念图用
Black Forest Labs 的 [FLUX.2 \[pro\]](https://bfl.ai)。读懂十万行 C++、逆向 `.def` 格式、
写完验证器，以前是几周的前置工作，现在一两天。

工具链都放在 [yzh119/vcmi](https://github.com/yzh119/vcmi) 的 `tools/creature-art/`。

素材是育碧的，衍生资源不分发；我们做的是工具和原创美术。VCMI 是别人做了十几年的东西，
有用的改动往上游提。
