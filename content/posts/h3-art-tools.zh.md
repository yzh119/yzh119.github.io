> 本文记录发布时的实现与测量。文中的版本号、费用和检查数量属于该阶段；后续兵种安装记录见[吸血鬼交付](/zh/posts/necropolis-vampires/)，现行工具入口见[独立仓库](/zh/posts/h3-art-tools/)。

美术工具已经从 VCMI 目录搬到了独立的公开仓库 [h3-art-pipeline](https://github.com/yzh119/h3-art-pipeline)。后续的绑定、动画、渲染和打包代码都在这里维护，VCMI 的旧目录只保留迁移说明。

公开内容包括 Python 和 Blender 脚本、配置、提示词、环境依赖，以及[复现说明](https://github.com/yzh119/h3-art-pipeline/blob/main/docs/REPRODUCING.md)。模型、原版提取素材和完整 mod 留在本地。美术进展继续放在博客，概念图、实际 Blender 高清静帧、动画和游戏内效果会分别标明。

目前仍然使用 Meshy：imagegen 生成概念图，Meshy 提供带贴图的基础模型和适合人形的自动绑定，Astra 编写本地修模、骨架修复、动作、渲染及打包工具。幽灵这种没有脚的模型使用本地骨架。仓库也保留了早期尝试的代码和记录。

有了代码和提示词，别人可以让自己的 AI 助手沿着这些步骤继续做。生成模型每次可能不同，手部、装备和骨架位置仍需检查；当前角色脚本里也有针对具体网格的处理，不能保证换一个生成结果就能原样跑通。复现文档明确保留了这些限制，以及 Meshy 调用的费用和中断恢复注意事项。

迁移当时重新跑了检查：38 个 Python 脚本语法解析通过；现有八兵种的验证结果与迁移前一致，188 条信息、0 警告、0 错误；墓园分层导出的 103 帧通过尺寸与透明轮廓检查。城镇工具现在可以读取仓库内固定版本的建筑配置，不再依赖 VCMI 源码目录的位置。本地已安装的美术资源没有变化。

代码沿用 GPL-2.0-or-later，迁移清单记录了原提交和文件哈希。这个代码许可不涵盖第三方美术。旧博客和 [VCMI fork 的 PR #10](https://github.com/yzh119/vcmi/pull/10) 保留历史过程，新工具的入口统一指向独立仓库。

迁移后的[吸血鬼交付](/zh/posts/necropolis-vampires/)已完成飞行、变身与本地重新绑定。迁移时的 38 个脚本、八兵种验证数字是当时的检查快照。
