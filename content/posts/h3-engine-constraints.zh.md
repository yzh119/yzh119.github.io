我想把英雄无敌 3 的兵种美术换掉，在 [VCMI](https://vcmi.eu) 上做。

动手生成任何东西之前，我先去读了引擎代码，想知道它到底要什么。结果发现一堆规矩，
基本没文档，而且**踩了不报错**——你只会得到一个看着别扭的兵种，还不知道哪儿不对。

## 画布尺寸只认第一帧

`CreatureAnimation` 从当前动画组的头一帧取尺寸：

```cpp
auto first = forward->getImage(0, size_t(type), true);
fullWidth  = first->width();
```

但 `pos.w`/`pos.h` 在单位创建时就定死了，后面每一帧都得从这个矩形里过：

```cpp
canvas.draw(image, pos.topLeft(), Rect(0, 0, pos.w, pos.h));
```

比待机帧大的，超出部分直接裁掉；比它小的，就悬在半空。所以每个动画组的每一帧
都得用同一张画布，靠透明像素填满。

## 站位不看兵种

`getStackPositionAtHex` 算绘制位置只看六边形——一个写死的 `basePos(-189, -139)` 加偏移，
兵种自己的尺寸压根不参与。

从 PNG 读进来的帧 `margins` 是 (0,0)，不像 `.def` 帧自带边距。换句话说，**兵种画在画布
哪个位置，就是唯一的锚点**。放偏了，单位要么浮空要么陷地，后面没有任何环节能补救。

## `verticalFlip` 是水平镜像

引擎只要一个朝向的图，另一边自己翻：

```cpp
reverse->verticalFlip();
```

而 `CSDL_Ext::verticalFlip` 翻的是每行**内部**的像素顺序——也就是左右镜像。`horizontalFlip`
才是上下翻。命名跟通常习惯正好反过来。

知道了是好事：美术量直接砍一半。

## 阴影和旗帜藏在调色板里

调色板前 8 个索引不是颜色，是语义：透明、两档阴影浓度、还有一个归属旗帜槽——引擎按玩家
给它上色。

重绘没有调色板，这几层只能显式给：`-shadow` 和 `-overlay` 两张配套图。待机和悬停组的
overlay 是**硬性要求**，鼠标划过部队时高亮的那圈白轮廓就是它。

## 各倍率共用路径

2x 的布局，引擎去查 `SPRITES2X/<name>.json`；而 JSON 里的 `basepath` 是**相对倍率前缀**
解析的。所以 1x 和 2x 的 JSON 里，basepath 和文件名应该写得**一模一样**，只有目录不同。
另外，就算只做高清，1x 那套也得给。

## 帧数可以改

JSON 动画格式是整组替换，「即使原动画更长」。重绘用多少帧随你，跟原 `.def` 不必一致，
播放时长每个兵种单独调。

## 顺手把归档也读了

要对齐，还得知道原版的数字：画布多大、多少帧、脚踩在哪。VCMI 有现成工具，但没装，
而格式简单到能直接啃。

LOD 是个扁平归档：偏移 8 是文件数，条目从 `0x5c` 起，16 字节名字 + offset + 大小 +
四个没用的字节 + 压缩后大小。压缩大小非零就是 zlib。

DEF 稍微绕一点：文件头、256 项调色板、若干块。每块是组号 + 帧数 + 八个未知字节 +
13 字节帧名 + 帧偏移。每帧 32 字节头，四种编码之一。`H3sprite.lod` 里 2565 个 def
全部解出来，四种编码都碰上了。

调色板这块照 VCMI 自己的转换表：

```
0     透明
1,2   阴影边缘    alpha 64
3,4   阴影主体    alpha 128
5     选中 / 归属旗帜
6,7   选中层下的阴影
```

所以**一个 def 帧是三张图叠在一起**，靠调色板索引区分：本体、地面阴影、待上色的白轮廓。
把这层编码解开，三张干净的图就出来了——正好就是替换美术要交的那三张。

## 骷髅到底是个什么尺寸

解码器跑通，目标就不用猜了：

```
画布      450 x 400，15 个动画组一致
地面线    y = 267，待机帧之间守到像素
兵种      待机 42 x 79，所有动作并起来 158 x 136
帧数      引擎认的 13 个组，共 82 帧
调色板    223 种颜色
```

两个数字改了我对这活儿的判断。

**42 × 79。** 整个兵种就这么大。放大才看得见的肋骨纹理，游戏里只占两三个像素——那是质感，
不是形。所以设计得先能压成一个剪影加三四块明暗，再细就是噪点，每帧的锯齿还不一样。

<figure>
  <img src="/images/vcmi/scale-reality.png" alt="骷髅的 1x / 2x / 4x">
  <figcaption>最左边是游戏真实绘制的大小：42 x 79。右边两张放大是给我们看的，玩家看不到。</figcaption>
</figure>

**223 种颜色。** 英雄无敌 3 的兵种当年就是 3D 预渲染的，它从来不是限定调色板的像素画。
我们走 3D 管线是**回到**原来的做法。
